# Aula 01 — Apresentação da disciplina e organização inicial do projeto

## Objetivo

Apresentar a disciplina, o projeto que será construído ao longo do semestre e estruturar o projeto Spring Boot inicial com todas as dependências necessárias.

## O que foi feito nesta aula

### Projeto criado via Spring Initializr

O projeto foi gerado em [start.spring.io](https://start.spring.io) com as seguintes configurações:

| Campo | Valor |
|---|---|
| Project | `Maven` |
| Language | `Java` |
| Spring Boot | `4.0.7` |
| Group | `br.unisinos` |
| Artifact | `ecommerce` |
| Java | `17` |

### Selecionar as seguintes dependências:
- SpringDoc OpenAPI 
- Lombok
- Spring Boot DevTools
- Spring Web
- Spring Data JPA
- Validation
- PostgreSQL Driver
